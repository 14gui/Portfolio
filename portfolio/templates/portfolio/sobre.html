A Arquitetura MVT

Este website foi desenvolvido sobre a framework Django seguindo o padrão de desenho MVT (Model View Template):

  • Model: Define a estrutura de dados (as tabelas e relações no SQLite que gerem as tuas UCs e Projetos).
  • View: Processa a lógica de negócio no servidor tratando do carregamento das páginas e dos formulários CRUD.
  • Template: Constrói a interface final em HTML utilizando tags dinâmicas do Django para injetar os dados da base de dados.

Tecnologias Core

Making Of / Diário de Bordo

{% filter markdownify %} ### 📖 Diário de Bordo e Evolução do Projeto O desenvolvimento desta aplicação foi um processo de aprendizagem contínua, focado na aplicação prática dos conceitos de engenharia de software e da framework Django. **📌 Registo de Commits Principais (GitHub)** * `init`: Configuração inicial do projeto e criação da aplicação base. * `feat`: Modelação da base de dados e estruturação da arquitetura MVT. * `fix`: Correção de erros de navegação e reestruturação das rotas (URLs). * `feat`: Implementação das operações CRUD completas para Projetos, Competências e Tecnologias. * `docs`: Integração da documentação técnica, wireframes e configuração do motor Markdown. **⚡ Dificuldades e Reflexões** O principal desafio durante o desenvolvimento foi garantir a correta comunicação entre as rotas (`urls.py`), a lógica do servidor (`views.py`) e a interface gráfica (`templates`). O Django exige um rigor elevado na passagem de variáveis e na validação de formulários, especialmente no tratamento de upload de imagens. Ultrapassar os erros de execução, como as falhas de redirecionamento, foi essencial para compreender o funcionamento interno da framework. O resultado final é uma plataforma estruturalmente sólida, que cumpre os requisitos propostos e serve como base fiável para desenvolvimentos futuros. {% endfilter %}
